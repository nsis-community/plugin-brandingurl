## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-brandingurl/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `BrandingURL.dll` to `Plugins/<variant>/`.
